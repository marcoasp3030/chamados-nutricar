# Chamados NUTRICAR

Sistema interno para gestão de chamados, suporte, projetos, checklists, inventário e inaugurações.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Documentação

- [`DOCUMENTACAO.md`](DOCUMENTACAO.md) — arquitetura, módulos, banco, integrações e deploy.
- [`deploy/README-SWARM.md`](deploy/README-SWARM.md) — publicação na VPS Nutricar com Swarm e Traefik.
- [`deploy/README.md`](deploy/README.md) — publicação dedicada com Docker Compose e Caddy.

Não versione `.env`, credenciais, dumps ou arquivos enviados pelos usuários.
